================================================================
 AutoLink  Ver 1.00
 Wi-Fi 自動復旧ツール (Parsec 常駐PC向け)
================================================================

■ 概要
  Parsec (リモートデスクトップ) のサーバ機として常駐させているPCで、
  Wi-Fi の切断や「インターネットなし」を自動で検知し、
  Wi-Fi の切断→再接続と Parsec の再起動を行うツールです。
  有線LANを用意できず Wi-Fi 接続で運用しているときの、
  外出中のネットワーク切断による可用性低下を減らすことが目的です。

  ・常時起動を前提に、低優先度・待機中心で動作します (負荷はごく小さい)
  ・状況は標準出力 (コンソールウィンドウ) に定期的にログ表示します
  ・1日ごとの切断時間と原因を、月別のログファイルに書き残します

  ※ 設定ファイル・ログ内では Parsec のことを「PerSec」と呼んでいる箇所があります
    (AutoLink.ini の PerSecProcess / PerSecPath など)。同じものを指します。


■ 動作環境
  ・Windows 10 / 11 (64bit)
  ・.NET Framework 4.x (Windows 標準。追加インストール不要)
  ・管理者権限 (Wi-Fi アダプタの操作やサービス起動に必要)
  ・Parsec for Windows (parsecd.exe)


■ ビルド方法 (exe の作り方)
  1. 起動中の AutoLink.exe があれば閉じる
  2. build.bat をダブルクリック
     (Windows 標準の csc.exe でコンパイルします)
  3. 「BUILD OK」と表示されれば AutoLink.exe が出来上がり

  ソースを変更したときも、同じ手順で作り直します。


■ 運用方法
  [起動]
    AutoLink.exe を実行します。起動のたびに管理者権限の確認 (UAC) が出ます。
    コンソールウィンドウにログが流れ続けます。閉じると終了します。
    多重起動はできません (2つ目は自動的に終了します)。

  [PC起動時に自動で立ち上げる]
    管理者のコマンドプロンプトで、次を1回だけ実行します
    (パスは実際の置き場所に合わせてください)。

      schtasks /create /tn "AutoLink" /tr "\"C:\Users\ちびことね\Documents\Aki\AutoLink\AutoLink.exe\"" /sc onlogon /rl highest

    ログオン時に最上位の特権で起動します (UAC なし)。
    解除するとき:  schtasks /delete /tn "AutoLink" /f

  [終了]
    コンソールウィンドウを閉じる、または Ctrl+C。
    終了時に、その日の切断サマリーをログファイルへ書き込みます。

  [動作の流れ]
    1. 30秒ごとに Windows と同じ方式でインターネット接続を確認します
       (msftconnecttest.com → だめなら google.com/generate_204)
    2. 異常 (Wi-Fi未接続 / 接続中だがインターネットなし) を検知したら、
       10秒間隔で再確認し、3回連続で異常なら復旧処理に入ります
    3. 復旧処理
         a. Parsec (parsecd.exe) をタスクキル
         b. Wi-Fi の状態を確認
              ・通常 (接続が切れただけ): Wi-Fi を切断
              ・Wi-Fi アダプタが netsh から見えない場合: Wi-Fi 無線のオン、
                WLAN AutoConfig サービスの起動、アダプタの有効化・再起動を試行
         c. 再接続に連続で失敗したときは、アダプタを無効化→有効化
         d. 記録済みのプロファイルで Wi-Fi に再接続 (最大45秒待機)
         e. 回復したら Parsec を起動
            (Parsec のサービスが先に起動し直している場合は、二重起動しません)
            回復しなかったら、ネットワークが戻った時点で Parsec を起動します
    4. 通常の「切断→再接続」で直らない場合も、約30秒後に再び復旧を試みます

  [ログの見方]
    [OK]    正常
    [WARN]  異常の検知 / 復旧処理の開始・終了
    [INFO]  復旧処理の各ステップ / 診断結果
    [ERROR] 復旧に失敗

  [切断サマリー]
    0:00 と アプリ終了時に、その日の合計切断時間 (概算) と、
    切断ごとの発生時刻・原因・復旧の仕方を logs フォルダ内の
    月別ログ (例: 202611_AutoLink.log) に追記します。

      ==== 2026-11-08 (日) ネットワーク切断サマリー ====
      記録日時: 2026-11-09 00:00:00   契機: 日次 (0:00)
      合計切断時間(概算): 2分15秒   切断回数: 2
        1. 00:41:16 - 00:41:48 (32秒)  原因: Wi-Fi切断 [...]  / AutoLinkの復旧処理(1回目)で回復

    ・開始時刻は「最初に異常を検知した時刻」、終了時刻は「回復を確認した時刻」です。
      確認間隔の分だけ実際とずれる概算値です。
    ・0:00 をまたぐ切断は、0:00 で区切って前日と当日に分けて計上します。
    ・同じ日に終了と再起動を繰り返すと、その日のサマリーが複数出力されます。
      後のものが、その時点までの累計です。
    ・原因の分類: Wi-Fi切断 / インターネット到達不可 / Wi-Fiアダプタ消失 / 疎通失敗


■ 設定 (AutoLink.ini)
  初回起動時に自動で作られます。変更後は AutoLink.exe を再起動してください。
  書式は「キー=値」、「#」で始まる行はコメントです。

  CheckIntervalSec       正常時の確認間隔 (秒)                  既定 30
  RetryIntervalSec       異常検知後の再確認間隔 (秒)            既定 10
  FailThreshold          何回連続の異常で復旧処理に入るか        既定 3
  ProbeTimeoutSec        疎通確認1回あたりのタイムアウト (秒)    既定 5
  ReconnectWaitSec       再接続後に回復を待つ最大秒数            既定 45
  AdapterResetAfterFails 復旧に何回連続で失敗したらアダプタの
                         無効化→有効化まで行うか                 既定 2
  RestartPerSec          復旧時に Parsec を再起動するか           既定 true
  PerSecProcess          Parsec のプロセス名 (拡張子なし)         既定 parsecd
  PerSecPath             parsecd.exe のフルパス
                         (空なら自動検出)                        既定 (空)
  WifiProfile            Wi-Fi プロファイル名
                         (空なら接続中のものを自動検出)          既定 (空)
  LogDir                 切断サマリーの出力先フォルダ。
                         相対パスは AutoLink.exe のあるフォルダ基準  既定 logs


■ ファイルの説明
  [配布・実行に必要]
    AutoLink.exe       本体 (build.bat で生成)

  [ビルド用 (改造しないなら実行には不要。作り直すときのために残してください)]
    build.bat          ビルドスクリプト (Windows 標準の csc.exe を使用)
    AutoLink.manifest  管理者権限を要求するための設定 (exe に埋め込まれます)
    AutoLink.ico       アイコン (exe に埋め込まれます)
    Program.cs         監視・復旧・Parsec 制御のメイン処理
    Outage.cs          切断時間の記録と、日次/終了時のサマリー出力
    State.cs           状態ファイル (AutoLink.state) の読み書き

  [実行中に自動で作られる]
    AutoLink.ini       設定ファイル (上記)
    AutoLink.state     状態ファイル。次の内容を保存します。
                         ・Parsec の場所 / 接続先 Wi-Fi のプロファイル名 /
                           Wi-Fi アダプタ名 (再起動後も使い回すためのキャッシュ)
                         ・その日の切断記録 (再起動をまたいで合計を保つため)
                       編集は不要です。不調のときは削除すると初期状態に戻ります。
    logs\              切断サマリーの出力先 (LogDir で変更可)
      yyyyMM_AutoLink.log   月別の切断サマリー (例: 202611_AutoLink.log)


■ 注意・制限事項
  ・切断時間は概算です (確認間隔の分だけずれます)。
  ・強制終了や停電などで終了処理が走らなかった場合、その時点で進行中だった
    切断の記録は失われます。次回起動時に、前日までの分は補完して出力します。
  ・Wi-Fi 機能がオフ (機内モードや物理スイッチ) の場合、無線を ソフトウェアで
    オンに戻せないことがあります。その場合は ERROR を出して再試行を続けます。
  ・USB の Wi-Fi アダプタが抜けた場合など、Windows からアダプタが認識されない
    状態は、ソフトウェアでは復旧できません。
  ・動作確認の状況:
      確認済み  Wi-Fi 設定からの切断 → 自動再接続 → Parsec の復旧
      未確認    ルーターのWAN断などによる「Wi-Fiは接続中でインターネットなし」の
                状態からの自動復旧 (処理の流れは同じ想定です)
  ・本ソフトは個人利用向けに作成したものです。使用による損害について、
    作成者は責任を負いません。
